# Fullstack Todo App

Застосунок для управління завданнями, розроблений як тестове завдання.

## Технологічний стек

- **Бекенд:** Node.js, Express.js, Sequelize (SQLite), JWT.
- **Фронтенд:** React, Vite, Tailwind CSS v4, React Query, Axios.

## Запуск проєкту локально

### 1. Запуск бекенду

Відкрийте термінал і виконайте:
\`\`\`bash
cd backend
npm install
npm run dev
\`\`\`
Бекенд запуститься на порту 5000 (або 5001), база даних SQLite створиться автоматично.

### 2. Запуск фронтенду

Відкрийте новий термінал і виконайте:
\`\`\`bash
cd frontend
npm install
npm run dev
\`\`\`
Фронтенд буде доступний за адресою: `http://localhost:5173`.
